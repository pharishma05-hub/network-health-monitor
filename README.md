# Network Health Monitor

Python script that monitors latency and packet loss across 6 targets
(router, Google DNS, Cloudflare DNS, Google, YouTube, GitHub) and
analyzes the results to separate local congestion from internet-side delay.

## Files
- network_monitor.py: the monitoring script
- network_log.csv: collected data (2,034 data points)
- Project summary PDF: method, findings and conclusion
- Screenshots: latency charts, packet loss table, pivot table

## Tools
Python, Google Sheets
